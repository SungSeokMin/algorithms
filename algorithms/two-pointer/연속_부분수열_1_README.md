# 연속 부분수열 1

## 문제 설명

양의 정수 배열과 목표 합 `m`이 주어질 때, 합이 정확히 `m`이 되는 연속 부분수열의 개수를 반환하라.

**예시:**
- 입력: `m = 6`, `array = [1, 2, 1, 3, 1, 1, 1, 2]`
- 합이 6인 연속 부분수열:
  - `[2, 1, 3]` (인덱스 1~3)
  - `[1, 3, 1, 1]` (인덱스 2~5)
  - `[3, 1, 1, 1]` (인덱스 3~6)
- 출력: `3`

---

## 접근 방식

### 알고리즘: 투 포인터 / 슬라이딩 윈도우 (Two Pointer / Sliding Window)

- **왜 이 방식인가?**: 배열의 원소가 양의 정수이므로, 오른쪽 포인터(rt)를 전진시키면 합이 단조 증가하고 왼쪽 포인터(lt)를 전진시키면 합이 감소한다. 이 단조성을 이용하면 모든 쌍을 확인하는 O(n²) 대신 O(n)에 해결할 수 있다.
- **핵심 패턴**: 가변 길이 슬라이딩 윈도우 패턴. rt를 매 반복마다 전진, sum이 m 이상이면 lt를 전진해 윈도우를 줄이는 방식.
- **풀기 전 체크리스트**:
  - 추적할 상태: 현재 윈도우 합(`sum`), 왼쪽 포인터(`lt`), 답(`answer`)
  - 입력: 양의 정수 배열 + 목표 합 m / 출력: 합이 m인 부분수열의 개수
  - 엣지케이스: 단일 원소가 m인 경우, m보다 큰 원소 존재 시 (양의 정수 보장이면 lt를 넘어서 줄임)
- **일반적인 접근 순서**:
  1. `lt = 0`, `sum = 0`으로 초기화
  2. rt를 0부터 배열 끝까지 전진
  3. `sum += array[rt]` 후 `sum === m`이면 answer 증가
  4. `sum >= m`인 동안 `sum -= array[lt++]` 후 `sum === m`이면 answer 증가
  5. 반환

---

## 내 풀이

```js
function solution(m, array) {
  let answer = 0;
  let lt = 0;
  let sum = 0;

  for (let rt = 0; rt < array.length; rt++) {
    sum += array[rt];
    if (sum === m) answer++;

    while (sum >= m) {
      sum -= array[lt++];
      if (sum === m) answer++;
    }
  }

  return answer;
}

console.log(solution(6, [1, 2, 1, 3, 1, 1, 1, 2]));
```

### 풀이 과정

1. rt를 전진시키며 `sum`에 `array[rt]`를 더함
2. `sum === m`이면 현재 윈도우가 정답 → `answer++`
3. `sum >= m`인 동안 왼쪽을 줄임: `sum -= array[lt++]`, 줄인 후 `sum === m`이면 또 `answer++`
4. rt가 끝에 도달할 때까지 반복

**핵심 로직 예시** (m=6, array=[1,2,1,3,1,1,1,2]):
- rt=3 도달 시 sum=7 → while 진입: sum-=1(lt→1)=6, answer=1; sum-=2(lt→2)=4 탈출
- rt=5 도달 시 sum=6 → answer=2; while 진입: sum-=1(lt→3)=5 탈출
- rt=6 도달 시 sum=6 → answer=3; while 진입: sum-=3(lt→4)=3 탈출

- **시간복잡도**: O(n) — lt, rt 각각 최대 n번 전진
- **공간복잡도**: O(1)

## Claude 풀이

기존 내 풀이가 슬라이딩 윈도우의 최적 구현이다. 더 나은 접근법이 없으므로 내 풀이를 최선으로 선택한다.

```js
function solution(m, array) {
  let answer = 0;
  let lt = 0;
  let sum = 0;

  for (let rt = 0; rt < array.length; rt++) {
    sum += array[rt];
    if (sum === m) answer++;

    while (sum >= m) {
      sum -= array[lt++];
      if (sum === m) answer++;
    }
  }

  return answer;
}
```

### 설명

이 풀이의 핵심은 **체크 위치가 두 곳**이라는 점이다:
1. rt를 추가한 직후: 새로 확장된 윈도우가 m인지 확인
2. lt를 줄인 직후: 축소된 윈도우가 m인지 확인

두 체크를 모두 해야 모든 경우를 빠뜨리지 않는다. 한 곳만 체크하면 일부 부분수열을 놓친다.

---

## 두 풀이 최종 비교

| 항목 | 내 풀이 (= Claude 풀이) | 완전탐색 대안 |
|------|------------------------|--------------|
| 핵심 아이디어 | 슬라이딩 윈도우 | 모든 (i, j) 쌍 탐색 |
| 시간복잡도 | O(n) | O(n²) |
| 공간복잡도 | O(1) | O(1) |
| 양수 배열 조건 활용 | 활용 (단조 증가 보장) | 미활용 |
| 구현 복잡도 | 중간 | 낮음 |

### 핵심 차이점

슬라이딩 윈도우가 동작하는 전제 조건은 **배열 원소가 양의 정수**라는 것이다. 음수가 포함되면 rt 전진 시 합이 단조 증가하지 않아 이 방법을 쓸 수 없다. 이 조건이 보장될 때 O(n²) → O(n)으로 획기적으로 개선된다.
