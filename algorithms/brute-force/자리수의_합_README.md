# 자리수의 합

## 문제 설명

정수 배열이 주어질 때, 각 정수의 자리수의 합이 가장 큰 수를 반환하라.  
자리수의 합이 같은 경우에는 더 큰 수를 반환한다.

**예시:**
- 입력: `[128, 460, 603, 40, 521, 137, 123]`
- 각 자리수의 합: 128→11, 460→10, 603→9, 40→4, 521→8, 137→11, 123→6
- 최댓값은 11이고, 128과 137이 동일 → 더 큰 수인 **137** 반환

---

## 접근 방식

### 알고리즘: 완전탐색 (브루트포스)

- **왜 이 방식인가?**: 배열의 모든 원소를 순회하며 각 원소의 자리수 합을 직접 계산해야 한다. 사전에 정렬하거나 특정 자료구조를 쓸 필요 없이 완전히 탐색하는 방식이 자연스럽다.
- **핵심 패턴**: 모든 원소를 순회하며 조건을 평가하고 최적값을 갱신하는 "선형 스캔 + 최댓값 추적" 패턴
- **풀기 전 체크리스트**:
  - 추적할 상태: 현재까지의 최대 자리수 합(`max`)과 해당 원소(`answer`)
  - 입력: 정수 배열 / 출력: 자리수의 합이 가장 큰 정수 하나
  - 엣지케이스: 자리수 합이 같을 때 → 더 큰 수를 선택
- **일반적인 접근 순서**:
  1. 최댓값 추적 변수 초기화
  2. 배열을 순회하며 각 원소의 자리수 합 계산 (나머지 연산 반복)
  3. 현재 자리수 합과 최댓값 비교 → 조건에 따라 갱신

---

## 내 풀이

```js
function solution(array) {
  let answer = 0;
  let max = Number.MIN_SAFE_INTEGER;

  for (const x of array) {
    let sum = 0;
    let temp = x;

    while (temp) {
      sum += temp % 10;
      temp = Math.floor(temp / 10);
    }

    if (max < sum) {
      max = sum;
      answer = x;
    } else if (max === sum && x > answer) {
      answer = x;
    }
  }

  return answer;
}

console.log(solution([128, 460, 603, 40, 521, 137, 123]));
```

### 풀이 과정

1. `max`를 `Number.MIN_SAFE_INTEGER`로 초기화하여 음수 포함 모든 경우 처리
2. 각 원소 `x`에 대해 `temp = x`로 복사 후, `% 10` → `Math.floor(/ 10)` 반복으로 자리수 합 계산
3. `max < sum`이면 최댓값과 정답 모두 갱신
4. `max === sum`이면 더 큰 수로만 `answer` 갱신 (동점 처리)

- **시간복잡도**: O(n × d) — n은 배열 길이, d는 최대 자리수
- **공간복잡도**: O(1)

## Claude 풀이

```js
function solution(array) {
  const digitSum = n => String(n).split('').reduce((acc, d) => acc + Number(d), 0);

  return array.reduce((best, x) => {
    const [bs, xs] = [digitSum(best), digitSum(x)];
    return xs > bs || (xs === bs && x > best) ? x : best;
  });
}

console.log(solution([128, 460, 603, 40, 521, 137, 123]));
```

### 설명

- 문자열 변환 후 `split`으로 자리수 분리 → `reduce`로 합산하는 `digitSum` 헬퍼 활용
- `array.reduce`로 배열을 단일 값으로 축약하며 최적 원소를 추적
- **장점**: 선언적이고 간결, 변수 관리가 적음
- **단점**: `String()` 변환과 `split` 비용이 있어 큰 수나 긴 배열에서는 while 방식보다 미세하게 느릴 수 있음

---

## 두 풀이 최종 비교

| 항목 | 내 풀이 | Claude 풀이 |
|------|---------|-------------|
| 핵심 아이디어 | while 루프로 나머지 연산 반복 | 문자열 변환 후 reduce |
| 코드 간결성 | 보통 (명시적 루프) | 높음 (함수형) |
| 가독성 | 직관적, 절차적 | 선언적, 간결 |
| 시간복잡도 | O(n × d) | O(n × d) |
| 공간복잡도 | O(1) | O(d) — split 배열 생성 |
| 동점 처리 | 명시적 조건문 | 조건 표현식 한 줄 |

### 핵심 차이점

내 풀이는 숫자 연산(`% 10`, `Math.floor`)으로 자리수를 추출하여 공간 효율이 좋다. Claude 풀이는 문자열 변환을 활용해 코드가 더 짧고 선언적이지만 split 시 임시 배열이 생성된다. 로직 정확성은 동일하며, 실무에서는 가독성 기준으로 선택하면 된다.
